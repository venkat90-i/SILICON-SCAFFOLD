# Silicon scaffold IDE (POC PnR v11)

**Silicon scaffold IDE POC PnR v11** (internally designated as the "Fixed PDN" build) pushes past the "Peak" by introducing one of the most critical and complex phases of physical ASIC design: the **Power Delivery Network (PDN)**. 

This release ensures your chip actually has the power grid necessary to function, and upgrades the internal visualizer to accurately render complex wire routing.


---

##  What's New in POC PnR v11 (Improvements)

This version bridges the gap between placing cells and actually giving them power, overhauling both the OpenROAD backend commands and the frontend Qt visualizer:

### 1. Dedicated "PDN" Generation Step
* **The New Ribbon:** The Backend execution ribbon has been expanded to include a dedicated **"PDN"** button right after Tapcells and before IO Pins (`["Init", "Floorplan", "Tapcells", "PDN", "IO Pins"...]`).
* **Automated Grid Synthesis:** Clicking this step executes a complex, multi-stage TCL sequence specifically tailored for standard nodes (like Sky130). It automatically:
  * Maps standard cell power pins (`VPWR/VGND`) and macro pins (`VDD/VSS`) to global power connections.
  * Defines the core voltage domain and establishes the power grid (`define_pdn_grid`).
  * Generates horizontal metal-1 (`met1`) followpins to connect the standard cells.
  * Generates vertical metal-4 (`met4`) power stripes with a specific pitch (27.2) and offset to blanket the core.
  * Triggers `pdngen` to finalize the vias and connections.

### 2. Advanced Routing Parser (The "NEW" Keyword Fix)
* **Previous Constraint:** The v10 `DEFParser` only understood basic rectangles (`RECT`) inside the `SPECIALNETS` block, missing all the actual wire traces and paths generated by the router.
* **PnR v11 Improvement:** The custom `DEFParser` has been vastly upgraded with state-machine logic to understand `ROUTED` wire segments. 
* It now accurately extracts wire widths, parses infinite arrays of coordinate paths, and handles the DEF `"NEW"` keyword to safely split disconnected route segments into a distinct `self.power_routes` array.

### 3. High-Fidelity Power Visualization
* **Visualizing Paths:** The `SiliconPeeker` canvas now imports `QGraphicsPathItem` and `QPainterPath` to draw true vector lines instead of just boxes. 
* **Smart Scaling:** If the visualizer drew the PDN grid at true scale when zoomed all the way out, the die would just look like a solid orange block. The IDE intelligently calculates a `thin_width` (`d.width() / 1200.0`) dynamically based on your chip's size. 
* **Result:** It draws crisp, flat-capped vector lines (`Qt.PenCapStyle.FlatCap`) representing your entire power grid overlaid on your standard cells, remaining perfectly visible and visually pleasing at any zoom level.
